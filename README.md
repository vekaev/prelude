# Prelude

**No day starts unplanned.**

A planner for Mac built on Apple Reminders and Calendar. Every evening it asks you to pick tomorrow's three most
important tasks and give them time in your calendar, then keeps them in front of you all day. No account, no server:
everything stays on your Mac.

[![Download for macOS](https://img.shields.io/badge/Download-macOS-000000?style=for-the-badge&logo=apple&logoColor=white)](https://github.com/vekaev/prelude/releases/latest/download/Prelude-mac.dmg)

</div>

## Install

**One line in Terminal** (no security prompt):

    curl -fsSL https://raw.githubusercontent.com/vekaev/prelude/main/install.sh | sh

It downloads the latest release, puts Prelude in Applications and opens it.

**Or the DMG:** [download](https://github.com/vekaev/prelude/releases/latest/download/Prelude-mac.dmg), open it
and drag Prelude to Applications. The first time, if your Mac says it can't check the app, open
System Settings ▸ Privacy & Security and click **Open Anyway** (once; Prelude isn't notarized).

Either way Prelude updates itself: once a day, or right away via *Prelude ▸ Check for Updates…*.
Needs macOS 14 or later, Apple Silicon or Intel.

## About this repo

This repo only holds Prelude's releases and its installer. The app's source code isn't public.
